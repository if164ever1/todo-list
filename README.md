# Todo List App

A simple React todo list application that displays a list of tasks and provides a starting point for building interactive todo features.

## Installation

1. Make sure you have Node.js installed.
2. Open a terminal in the project folder.
3. Install dependencies:

```bash
npm install
```

## Run the development server

Start the app locally with:

```bash
npm run dev
```

Then open the URL shown in the terminal (usually `http://localhost:5173`) to view the app.
